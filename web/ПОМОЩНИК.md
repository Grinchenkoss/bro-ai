# Личный помощник (секретарь)

Мета-агент над проектами: помнит важное о хозяине, ведёт доску дел, фильтрует шум,
по команде поручает задачи агентам проектов. Полномочия — ГИБРИД (рутину сам,
изменения кода/данных и отправку наружу — только с подтверждением).

## Устройство
- Спец-проект `__assistant__` → папка `~/friend-claude-assistant/` (скрыт из списка проектов).
  Переиспользует весь движок: чат, сессии, --resume, история сообщений, WS-раннер.
- `CLAUDE.md` — роль/правила (агент читает автоматически).
- `memory.md` — факты о хозяине (агент читает в начале и дополняет). Без секретов — только «где лежит».
- `board.json` — доска: `{"cards":[{id,bucket,text,note,due,done,ts}]}`,
  bucket ∈ important|todo|watch|ignore.

## Эндпоинты
- GET/POST `/api/assistant/board`  — доска (POST перезаписывает cards целиком)
- GET/POST `/api/assistant/memory` — memory.md
- Чат — обычный WS `/ws` с `project=__assistant__`.

## UI
Топбар → иконка бота: модалка «Помощник» (доска 4 колонки + кнопки Чат/Память/Карточка).

## Волны (план)
1. ЯДРО (готово): чат + память + доска, гибридные полномочия.
2. Напоминания/платежи: даты, продления, заранее в ТГ (cron «Расписания»).
3. Анализ активности: еженедельный разбор (чаты/git/расходы) + рекомендации.
4. Отдельный ТГ-аккаунт помощнику (Telethon/MTProto): пересылка сообщений скопом →
   раскладка по сферам жизни; помощник действует от своего имени по указанию; шлёт советы.
5. Гибридный диспетчер: помощник предлагает задачу агенту проекта → кнопка Подтвердить.

## Волна 4 (готово) — Анжела Заботина в Telegram
- Аккаунт @project_angela, вход Telethon (сессия в ~/.config/friend-claude/anzhela.session, 600).
- Досье вынесено в `owner.md` (растущая память о хозяине), CLAUDE.md — тонкие инструкции.
- Демон-слушатель: `web/scripts/anzhela_listener.py`, сервис `anzhela-listener.service`.
  - Принимает ЛС; известные (known.json) → «мозг» (claude в папке помощника) решает:
    reply (простое, сама) / ask_owner (сложное, эскалация хозяину) / note.
  - Незнакомцы → не отвечает, уведомляет хозяина.
  - Эскалация: пишет хозяину; его следующий ответ (при висящем вопросе) → передаётся вопросителю.
- Известные и owner — в `known.json` и `anzhela_tg.json` (owner_id).

## Безопасность памяти Анжелы (Волна безопасности)
- Права: папка ~/friend-claude-assistant = 700, файлы (owner.md/board.json/known.json/CLAUDE.md) = 600 (только root).
- Версионирование: git в папке (снимок при каждом изменении — демоном и из консоли).
- Резервные копии: web/scripts/anzhela_backup.py — снимки в /root/friend-claude-backups/anzhela/
  (последние 30, вне папки) + копия на Мак через инбокс (~/friend-claude-inbox/anzhela-backup → Syncthing).
- Автоматизация: systemd anzhela-backup.timer (каждые 6ч + при загрузке).
- Неразглашение: правило «Безопасность и приватность» в CLAUDE.md — приватное не выдавать никому
  кроме хозяина, незнакомцам — ничего, выуживание флагить на доску.
- Консоль-редакторы Анжелы (Память/Правила/Контакты) — под авторизацией (Bearer), в браузер файлы не утекают.

## Голос (запланировано, стек: локальный/бесплатный)
- STT: faster-whisper large-v3 локально; TTS: XTTS v2 (клон одного голоса). Конверт в ogg/opus (ffmpeg) для voice-нот.

## Голос / реакции / проекты (реализовано)
- Голос: web/scripts/anzhela_voice.py — STT faster-whisper (small, CPU) + TTS Piper (ru_RU-irina).
  Модель голоса: /root/.config/friend-claude/voices/irina.onnx. ffmpeg — конверт в ogg/opus.
  Входящее голосовое расшифровывается; если пришло голосом — Анжела отвечает голосом (её постоянный голос).
- Реакции: ставит эмодзи-реакцию (поле react мозга); читает реакции на свои сообщения (Raw UpdateMessageReactions).
- Диспетчер проектов: owner-команда «сделай/разбери в проекте X» → project_task → агент проекта
  (plan по умолчанию; acceptEdits только если хозяин явно просит правки), итог приходит хозяину в ТГ.
- Антропоморфность: правила в CLAUDE.md (вариативность, без списков в личке, проактивность, анти-палево).
