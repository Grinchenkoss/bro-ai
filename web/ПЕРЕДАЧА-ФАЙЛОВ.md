# Передача файлов агенту (inbox)

Два способа положить файл так, чтобы агент забрал его напрямую с диска
(мимо чата, любые форматы, секреты). Оба ведут в одну папку на сервере:

    /root/friend-claude-inbox        (права 700, файлы 600)

## 1. Веб-консоль (телефон/браузер) — работает сразу

Топбар → иконка «Передача» (📥). Drag&drop или выбор файлов.
Список: скачать, удалить, скопировать путь (⧉) — путь можно дать агенту в задачу.

Эндпоинты (auth = Bearer <пароль>, как везде):
- POST `/api/inbox/upload`  (multipart, поле `file`) — нужен `python-multipart`
- GET  `/api/inbox/list`
- POST `/api/inbox/delete`  `{name}`
- GET  `/api/inbox/file?name=&token=<пароль>`

## 2. Физическая папка на Маке — Syncthing (авто-синхронизация)

Настоящая папка в Finder, двусторонняя синхронизация за секунды, без облака.

### Сервер (уже настроено)
- пакет `syncthing`, сервис `syncthing@root` (systemd)
- конфиг: `/root/.local/state/syncthing/config.xml`, GUI: `127.0.0.1:8384` (только localhost)
- папка Syncthing `fc-inbox` → `/root/friend-claude-inbox` (fsWatcher, rescan 10s)
- firewall: открыты `22000/tcp` и `22000/udp`
- **Device ID сервера:** `WKNZSO7-C62Z6OO-EPP742O-EDFKRYX-T5BZRKJ-HLZ35DL-WRGD7WS-TO5HAAG`

### Мак (разово)
1. `brew install syncthing && brew services start syncthing`
2. открыть `http://127.0.0.1:8384`
3. Actions → Show ID → скопировать свой Device ID
4. Add Remote Device → вставить Device ID сервера → Save
5. когда сервер расшарит папку — принять, путь указать `~/FriendClaudeDrop`
