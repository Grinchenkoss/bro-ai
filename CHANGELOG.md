# Changelog

Все заметные изменения продукта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/),
версии по [SemVer](https://semver.org/lang/ru/). Партнёр видит этот файл при `deploy/update.sh`.

Как читать: `Added` — новое, `Changed` — изменено, `Fixed` — исправлено, `Removed` — удалено.

## [Unreleased]
### Added
- Панель: движок и модель Claude перенесены в шапку окна (к названию); строка инструментов
  освобождена под статус агента, действия/режим прижаты вправо.
- Панель: индикатор реальной модели + effort (`/api/defaults` из settings.json; «авто (Opus)»,
  уточняется до реальной модели из событий агента, напр. «Opus 5 · high»).
- Мобилка: левый и правый бургеры одного размера/иконки; правый бургер у края; «Настройки»
  перенесены внутрь правого меню; правое и левое меню симметричны (одинаковая ширина/выезд).
- Свайп-жесты: от левого края — меню проектов, от правого — доп-меню; обратный свайп закрывает.
- Мобилка: шестерёнка настроек и правый бургер прижаты к правому краю; логотип убран из
  топбара (освободили место); правое меню — компактный выезжающий справа drawer (не фуллскрин).
- Панель проекта: действия (проверка/diff/PR) убраны в выпадающее меню «Действия» (иконка+название),
  строка модели освободилась под статус работы агента.
- Аналитика: «5-час. окно живёт ещё Xч Ym» с иконкой часов в стиле проекта.
- Иконка настроек — аккуратная симметричная шестерёнка.
- Настройки: **смена пароля консоли** (эндпоинт `/api/password`, применяется вживую);
  иконка настроек заменена на **шестерёнку**.
- Мобильный **правый бургер** — доп-опции (помощник, поиск, активность, аналитика, студия,
  галерея, передача, расписания, веб-страницы) собраны в подписанное меню; в топбаре на мобиле
  остаются только чип лимитов и настройки. Два бургера: слева проекты, справа опции.
- Модалка **«Веб-страницы домена»** — список опубликованных страниц (название/описание/URL),
  переход, удаление (в т.ч. папок-сайтов), показ логина/пароля приватной зоны. Вложенные
  зеркала/архивы сворачиваются в один пункт, чтобы не засорять список (`/api/pages*`).
- Опубликована страница «Анжела — каталог возможностей» на домене превью (приватная зона).
- Консоль: в выводе агента голые ссылки `http(s)://…` стали кликабельными; у блоков кода —
  кнопка «копировать».
- `native-app-kit/`: симметричный релиз-флоу для нативного приложения (партнёрская часть) —
  `release.sh` (SemVer-тег + bump marketing/build версии + CHANGELOG), шаблон CHANGELOG, README
  с двусторонним PR-обменом. `docs/COLLABORATION.md` дополнен разделом про приложение.
- Консоль: авто-проверка обновлений при заходе — баннер «доступно обновление vX.Y.Z»
  с показом CHANGELOG («что нового») и кнопкой «Обновить» (применяет `deploy/update.sh`
  отвязанно, консоль сама перезапустится). Эндпоинты `/api/update/check`, `/api/update/apply`;
  у `deploy/update.sh` появился флаг `--yes`.
### Changed
- PWA: `index.html`/`sw.js` отдаются с `Cache-Control: no-cache` — установленное на айфон
  веб-приложение подтягивает свежий UI после перезапуска (без ручной чистки кэша).
### Fixed
- Мобильная вёрстка консоли: крестик закрытия окна больше не уезжает вниз; индикатор
  выполнения вынесен на отдельную строку (не наезжает на ряд кнопок); кнопка отправки
  выровнена вровень со строкой ввода; остатки лимитов (5ч/неделя) теперь видны на мобиле
  сразу после логотипа.

## [0.1.0] — 2026-08-10
Первый зафиксированный релиз — базовый «агентский сервис».

### Added
- **Веб-консоль**: окна проектов, живой запуск агента (stream-json), режимы readonly/auto,
  выбор модели, история чатов.
- **Фоновые прогоны**: задача выполняется на сервере и переживает сон устройства; при
  возврате клиент до-цепляется и досматривает пропущенное (реплей по курсору).
- **Реальные лимиты Claude** (5-часовое + недельное окно) в консоли и аналитике — из
  rate-limit заголовков API.
- **Аналитика расхода**: токены по дням и проектам.
- **Telegram-бот** — пульт к агенту с телефона (только владелец).
- **Помощница** (отдельный Telegram-аккаунт): входящие/эскалация владельцу/задачи агентам
  проектов; память (owner.md, board.json, known.json); голос (STT/TTS); реакции.
- **Генерация контента**: `shared/gen.py` — Gemini image / html / video / text для проектов.
- **Передаточная папка** (inbox) + синхронизация через Syncthing.
- **Превью-домен**: брендовая заглушка, стильная 404, приватная зона под basic-auth.
- **graphify**: пиновый локальный граф знаний по коду + MCP (в VS Code и в консоли).
- **Инфраструктура**: Caddy (авто-TLS), netmon (мониторинг сети), устойчивость DNS (unbound).
- **Деплой-кит**: `deploy/install.sh` + двухфазный мастер `deploy/wizard.py` под свои аккаунты.
- **Обмен версиями**: `deploy/update.sh` (получать обновления с показом изменений),
  `deploy/release.sh` (выпускать релизы), документация в `docs/`.
