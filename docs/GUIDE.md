# FRIEND_CLAUDE — гайд по продукту

Что это, что умеет и как пользоваться. Для владельца экземпляра и его команды.

## Обзор
Персональный «агентский сервис» вокруг Claude Code: агент живёт на сервере, а ты
управляешь им из **браузерной консоли**, из **Telegram** и через **помощницу**.
Всё выполнение — на сервере, клиентский экран не обязателен.

## 1. Веб-консоль (`https://console.<домен>`)
Главный инструмент. Вход по паролю (задан при установке).

- **Окна проектов** — каждый проект открывается своим окном; можно вести несколько.
- **Запуск агента** — пишешь задачу, агент выполняет (Read/Write/Edit/Bash/… или только чтение).
  - Режим окна: **readonly** (разбор, план — ничего не меняет) или **auto** (правит код).
  - Выбор модели на окно (opus/sonnet/haiku) — по умолчанию модель подписки.
- **Фоновые прогоны** — можно поставить задачу и **закрыть/погасить устройство**: работа
  продолжится на сервере, вернёшься — консоль до-цепится и покажет пропущенное и результат.
- **Чаты** — история сессий проекта, можно продолжить (`--resume`).
- **Лимиты Claude** (чип вверху) — реальные проценты 5-часового и недельного окна + время сброса.
- **Аналитика расхода** — токены по дням и проектам, реальное окно в процентах.
- **Передача** — кнопка/папка для файлов агенту напрямую (см. §5).
- **Помощница** — вкладки Доска/Память/Правила/Контакты/Журнал.

## 2. Telegram-бот
Пульт к агенту с телефона (отвечает только владельцу, `OWNER_ID`). Пишешь задачу —
агент выполняет в выбранном проекте, бот присылает результат. Планировщик задач по расписанию.

## 3. Помощница (по желанию)
Отдельный Telegram-аккаунт со своим номером. Принимает входящие от известных людей,
отвечает сама на простое, сложное — эскалирует владельцу, по команде заводит задачи
агентам проектов. Ведёт живую память о владельце (`owner.md`), доску дел (`board.json`),
список известных (`known.json`). Умеет голос (расшифровка входящих + озвучка ответов),
реакции, генерацию.

## 4. Генерация контента
Общий инструмент для проектов (нужен `GEMINI_API_KEY`):
```
python3 shared/gen.py image "промпт" out.png [--edit in.png]   # Nano Banana
python3 shared/gen.py html  "описание страницы" out.html        # адаптивный HTML
python3 shared/gen.py ask   "вопрос"                            # текст
python3 shared/gen.py video "промпт" out.mp4 [--fast]           # Veo
```

## 5. Передаточная папка
Файлы агенту мимо чата: клади в `~/friend-claude-inbox/` (или синхронизируй с Mac через
Syncthing → папка `~/FriendClaudeDrop`). Агент читает оттуда; результаты, которые он кладёт
туда, прилетают обратно на Mac.

## 6. Превью-домен (по желанию)
Показать заказчику результат ссылкой, а не файлом: положи HTML в `/srv/previews/<проект>/`
→ `https://projects.<домен>/<проект>/`. Приватная зона `/_private/*` — под паролем.

## 7. graphify — граф знаний по коду (по желанию)
Строит граф проекта, чтобы агент ориентировался быстрее (в VS Code и в консоли — как MCP).
Пиновая локальная установка (не автообновляется). См. раздел в `CLAUDE.md` проекта.

## Управление сервисами
```bash
systemctl status friend-claude-web friend-claude-bot anzhela-listener
journalctl -u friend-claude-web -f
```

## Обновления
Получить свежую версию продукта с показом изменений:
```bash
sudo bash deploy/update.sh
```
Подробнее про обмен версиями между тобой и партнёром — `docs/COLLABORATION.md`.
